# Map Overlay Studio

تطبيق ويب عربي لإسناد مخطط هندسي جغرافياً فوق خرائط Google، ثم ضبط موضعه ودورانه ومقياسه وتصدير النتيجة بصيغتي PNG وPDF.

## المزايا

| الميزة | الوصف |
|---|---|
| رفع المخططات | يدعم ملفات PDF وPNG وJPG وSVG. |
| المعايرة | سحب الطبقة وإيماءات إصبعين وأزرار ضبط دقيقة للحركة والتدوير والتكبير. |
| القفل | قفل مستقل للخريطة وللمخطط لتفادي الحركة غير المقصودة. |
| الطرق والشفافية | إظهار أو إخفاء طبقات الطرق، ومنزلق شفافية دائم للمخطط. |
| النسخ واللصق | تصدير المعايرة الحالية كنص موحّد أو لصق معايرة محفوظة وتطبيقها فوراً. |
| التصدير | تحديد نطاق وتصدير خريطة مدمجة عالية الدقة كصورة PNG أو ملف PDF عند 300 DPI. |

## التشغيل المحلي

يتطلب المشروع Node.js 22 وpnpm.

```bash
pnpm install
pnpm dev
```

لفحص الشفرة وتشغيل الاختبارات:

```bash
pnpm check
pnpm test
```

## سير العمل

ارفع مخططاً، وانتقل بالخريطة إلى المنطقة المناسبة، ثم اقفل الخريطة عند الحاجة واسحب المخطط فوق الموقع. استخدم الإيماءات أو أزرار التحكم الدقيق حتى تصل إلى التطابق المطلوب، واحفظ الحالة محلياً على الجهاز. بعد ذلك حدّد نطاق التصدير ونزّل النتيجة.

## صيغة المعايرة

يمكن للتطبيق نسخ المعايرة الحالية إلى الحافظة أو تطبيق نص معايرة من هذا الشكل. استبدل القيم بين القوسين بقيم مشروعك:

```text
MAP_OVERLAY_CALIBRATION_V1
lat=<latitude>
lng=<longitude>
spanLng=<longitude-span>
rotation=<degrees>
opacity=<10-100>
mapZoom=<1-20>
roadsVisible=<true|false>
```

## الخصوصية

لا يتضمن المستودع أي مخطط هندسي مرفوع أو معايرة أو موقع خاص بالمستخدم. يبدأ التطبيق من عرض عالمي عام، ويُخزّن ما تحفظه من جلسات معايرة محلياً في متصفحك فقط.

## البنية التقنية

يستخدم المشروع React وTypeScript وVite وExpress وGoogle Maps عبر التكامل المدمج. تُدار التحويلات الجغرافية وخطة التصدير عالية الدقة داخل `client/src/lib/overlayMath.ts`، بينما تُدار الواجهة في `client/src/pages/Home.tsx`.
